step 1. download 7zip and install it
step 2. download vbox for windows and install it
step 3. download kali Linux for vbox or just the normal one.
step 4. by now vbox is ready, open it
step 5. create the vbox network (ctr + shift + c)
step 6. create the vbox network to 10.0.0.0/24
step 7. now press on open to upload kali Linux vbox
step 8. open setting for kali Linux vbox
step 9. on general change feature setting to bidirectional
step 10. on system change the base memory
step 11. on the system settings, change the number of cpus to 3 or 4
step 12. on display settings, change the video memory that fits and press okay
step 13. now run vm for kali Linux
step 14. vm will open, press the graphical install on the interface, then the installation will begin.
step 15. when its completed, edit network connections by pressing the network wired icon
step 16. press wire connection 1
step 17. on the ipv4 stings, set the DNS server to 10.0.0.1,
step 18. check the network ipv4 connection by turning it down and up. then you are done if it responds nicely.
